# 모의고사집 개정 의견 조사

한국상담학회 전문상담사 2급 모의고사집(7과목 700문항) 구매자 대상 피드백 수집 설문.
최규하상담심리연구소(2CPlab.)

## 구조

정적 HTML(GitHub Pages) → Google Apps Script 웹앱 → Google Sheets

서버와 데이터베이스가 없습니다. 응답은 시트에 직접 쌓입니다.

## 파일

| 경로 | 역할 |
|---|---|
| `index.html` | 설문 페이지 (GitHub Pages로 배포) |
| `backend/Code.gs` | Apps Script 백엔드 (구글 시트에 붙여넣는 코드) |

## 설치

1. 구글 시트 생성 → **확장 프로그램 → Apps Script**
2. `backend/Code.gs` 전체를 붙여넣고 저장
3. **배포 → 새 배포 → 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
4. 발급된 `/exec` URL을 `index.html`의 `ENDPOINT`에 입력 후 커밋

## 설문 구성

22문항, 6개 섹션, 예상 소요 8분.

- 01 구매 확인 (2)
- 02 학습 사용 경험 (4)
- 03 실제 시험과의 비교 (4) — 개정 방향을 결정하는 핵심 섹션
- 04 교재 품질 (5)
- 05 구매 결정 (4)
- 06 동의 및 발송 정보 (3)

서술형 3개 문항(Q10, Q15, Q17)은 100자 이상 필수이며, 입력 중 실시간 글자수 미터가 표시됩니다.

## 마감 후 처리

1. Apps Script → **배포 관리 → 보관처리** (접수 차단)
2. 기프티콘 발송 완료 후 시트의 연락처 열 삭제
3. 이 저장소 비공개 전환 또는 삭제

## 주의

- `ENDPOINT`와 `ACCESS_KEY`는 클라이언트 코드에 노출됩니다. `ACCESS_KEY`는 보안 장치가 아니라 자동 크롤러를 거르는 문턱입니다.
- 페이지에 `noindex`가 설정되어 검색 엔진에 노출되지 않습니다.
